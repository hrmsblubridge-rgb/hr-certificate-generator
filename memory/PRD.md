# PRD — Internship Certificate Editable Template

## Original Problem Statement
Convert the uploaded BluBridge Internship Certificate PDF into a reusable
template by turning four specific values — Name, Designation, Commenced on
Date, Concluded on Date — into manually editable fields for HR use, while
preserving the original document EXACTLY (font, size, weight, alignment,
spacing, margins, header, footer, logo, signature, layout).

## Architecture
- **Source PDF**: `backend/static/Aravind_Krishna_Original.pdf` (untouched copy)
- **Editable template**: `backend/static/Internship_Certificate_Template.pdf`
  generated by `work/make_editable.py` using PyMuPDF:
    1. `page.search_for()` locates the four target value strings
    2. `add_redact_annot(fill=white)` + `apply_redactions()` removes only
       those text glyphs (everything else — including the watermark logo,
       header, footer, signature, surrounding text — is untouched)
    3. AcroForm text widgets are inserted at the exact same rectangles
    4. AcroForm `/DR/Font/RobotoB` is wired to the document's already-embedded
       Roboto-Bold font (xref 9), and every widget `/DA` is patched to
       `0.137 0.137 0.231 rg /RobotoB 10 Tf`; `NeedAppearances=true` so any
       text the HR user types renders in Roboto-Bold 10pt matching the
       original value styling exactly
- **Backend (FastAPI)** — three endpoints under `/api/template/*`:
    - `GET /api/template/download` → editable PDF (attachment)
    - `GET /api/template/preview`  → editable PDF (inline, for iframe)
    - `GET /api/template/original` → original PDF
- **Frontend (React + Tailwind)** — single-page UI:
    - Header with primary "Download editable PDF" CTA
    - In-page iframe preview of the editable template
    - Toggle to compare with the original certificate
    - Sidebar listing the four editable fields and their original values

## Core Requirements (all met)
- [x] Original document preserved exactly (no font / size / weight / alignment / spacing / margin / header / footer / logo / signature / layout changes)
- [x] Only the four specified values converted into editable form fields
- [x] Fields appear in the same positions as the original values
- [x] Surrounding text unchanged
- [x] Blank by default (HR enters the values)
- [x] No additional fields, no wording changes, no design changes
- [x] Output is a downloadable PDF preserving original appearance
